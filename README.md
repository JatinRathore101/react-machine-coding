# React Machine Coding

Is repo me **React.js machine coding round** ke common interview problems ke solutions rakhe jaate hain.

Frontend interviews ke machine coding round me jo questions baar-baar poochhe jaate hain — progress bars, accordion, debounced search, infinite scroll, star rating, modal, todo list waghairah — unka ek-ek working implementation yahan milega, apne alag folder me.

## Kya milega har solution me

- Ek self-contained folder `src/<problem-name>/` ke andar — component, constants aur helper files.
- Sirf React hooks, koi heavy external library nahi (machine coding rounds ki usual constraint).
- Jahan zaroori ho wahan ek `SRS.md` — problem statement, approach, implementation details aur trade-offs.
